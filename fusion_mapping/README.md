# 多源点云融合 + 官方模型形状参照（RMUC 2026 场地）

> 把**两拨人各自扫的场馆点云**配准、融合成一套场地坐标系下的点云，
> 再用**官方场地模型**做形状参照、扫描做尺寸/位形依据，产出干净、规整、可直接用于
> 建图 / 仿真 / 雕刻的场地级点云。
>
> 核心分工：**扫描 = 尺寸与实装位形的唯一依据；官方模型 = 形状与拓扑参考**（不整体硬套）。

## 效果

| 指标 | 结果 |
|---|---|
| 场馆级配准（2D 占用相关性 + 3D ICP） | 2D chamfer 中位 **6.4 cm** |
| 点-面精配准后（场馆级 3D） | 中位 **13.7 cm**（受两次扫描覆盖差异限制） |
| 场地区域跨扫描一致性 | 中位 **6.9 ~ 8.4 cm** |
| 融合点云 | **4,719,574** 点（ERASOR2 + red1） |
| 去动态/去雾后 | **1,810,798** 点 |
| 官方模型形状参照最终点云 | **759,242** 点，地面 std ≈ 0 m |
| 最终点云到真实扫描距离 | 中位 **4.7 cm** / P90 19.5 cm |

典型产物：官方坐标系下、结构规整、无雾无人的场地级点云（PCD + 彩色 PLY，可直接进 Blender）。

## 流程

```
┌─ 输入 ────────────────────────────────────────────────────────────────┐
│  A. 参考扫描（ERASOR2 场馆点云，SUMA 坐标系）                           │
│  B. 第二拨扫描（red1 场馆点云，自有坐标系）                              │
│  C. 官方场地模型（RMUC 2026，独立坐标系，仅作形状参考）                  │
└──────────────────────────────────────────────────────────────────────┘
        │
 ① 场馆级粗配准   2D 占用（z 2~12 m 结构带）+ 全角度旋转搜索 + FFT 平移
        │         → 多候选 3D 点-点 ICP（trimmed）→ 取 chamfer 最小
        ▼
 ② 点-面精配准   法向 PCA + trimmed point-to-plane ICP（带线搜索）
        │         → 4×4 矩阵（源扫描 → 场馆坐标系）
        ▼
 ③ 融合           应用矩阵 → 场馆→场地坐标（旋转/平移/地面平面）→ 裁剪 → 合并
        ▼
 ④ 去动态/去雾    官方模型邻近过滤（<0.30 m）+ 0.1 m 体素连通块过滤 + 地面平面拟合压平
        ▼
 ⑤ 官方模型形状    1.5 m 块局部偏移场（连续、无接缝）→ 移动官方模型点
        │         结构点用扫描证据门控；地面整体压平 z=0；2 cm 去重
        ▼
 ⑥ 局部修复       隧道/通道等"模型是实心、现场是开口"的区域，用真实扫描点替换
        ▼
┌─ 输出 ────────────────────────────────────────────────────────────────┐
│  场地坐标系点云（x∈[0,28] y∈[0,16] z=离地高度，地面 z≈0）             │
│  PCD（x y z）+ PLY（按高度着色，Blender 可直接打开）                    │
└──────────────────────────────────────────────────────────────────────┘
```

## 关键设计点

1. **场馆级而不是场地级配准**：场地只有 28×16 m，特征少、又接近 180° 对称，
   直接场地配准容易锁到错误位姿；用整个场馆（看台、环墙、周边结构）做配准，
   再验证到场地区域，跨扫描一致性从"一塌糊涂"收敛到 6~8 cm。
2. **先点-点后点-面**：点-点 ICP 把位姿拉到邻域内，再用带正确雅可比的
   point-to-plane + 线搜索把残差减半；尺度必须固定为 1（否则会像早期实现一样
   每轮乘 0.97，三十轮后整团点云缩成 40%）。
3. **不用整体刚体硬套官方模型**：官方模型与实装存在零件级安装误差，
   用 **1.5 m 块局部偏移场**（中位数 + 距离变换补空 + 平滑）把模型"搬到"实装位形，
   既保留零件级差异，又不会像"逐零件独立摆位"那样在接缝处裂开。
4. **形状与尺寸分离**：最终点云的形状/拓扑来自官方模型，位姿/尺寸来自扫描；
   结构点必须被扫描证据支持（默认 0.35 m），地面统一压平到 z=0。
5. **模型是理想化资产，现场有开口**：官方模型常把隧道/通道做成实体，
   最后一步按人工标注的隧道区域用真实扫描点替换，保证通道贯通。

## 使用

```bash
pip install -r requirements.txt
# 修改 run_pipeline.sh 顶部的输入路径，然后：
./run_pipeline.sh
```

单步运行（示例：场馆级配准）：

```bash
python3 scripts/01_register_venue.py \
    --ref erasor2_venue.pcd --src red1.pcd \
    --out-matrix out/src_to_venue.txt --out-report out/reg_coarse.json
```

每个脚本都接受 `--help`，参数含义见 `configs/example_params.yaml` 与 `docs/method.md`。

## 输入数据约定

| 文件 | 坐标系 | 说明 |
|---|---|---|
| 参考扫描（ERASOR2） | 场馆/SUMA 坐标系 + 已转换的场地点云 | 需要 `--ref`（场馆级）与 `--ref-field`（场地坐标）两份 |
| 第二拨扫描（red1） | 自有坐标系 | 10.4M 点场馆级点云 |
| 官方场地模型 | 独立坐标系 | 1M 点 PCD；先用 `--rot/--center/--translate` 对齐到场地区域，或用场地配准矩阵转换 |

> 数据本身（ERASOR2 数据集、red1、官方模型）不随仓库分发；脚本只依赖点云文件路径。
> RMUC 2026 场地的坐标变换常数在 `configs/example_params.yaml` 中给出，
> 其它场地换成自己的旋转/平移/地面平面参数即可。

## 已知限制

- **平面滑移歧义**：单个平面片只能可靠观测出平面偏移与倾斜，板面内的平移无法从
  平面本身定出（需要边缘/角点约束）；因此不要用"逐面板刚体位姿"当作安装误差真值。
- **场馆对称性**：八角形场馆存在 45° 旋转对称，配准需要多候选验证（脚本已做），
  必要时用场地内部非对称结构人工确认。
- **官方模型精度**：模型是设计尺寸，实装可能存在厘米~十厘米级差异；本方法用偏移场
  吸收这些差异，而不是把扫描硬压到模型上。
- **隧道/开口**：模型与现场不一致的位置必须人工标注（`configs/tunnel_zones.json`），
  脚本无法自动判断"哪里应该是空的"。
