# 方法细节

本文档补充 `README.md` 中的流程，记录关键公式、参数、实测结果与踩坑过程，
方便复现和迁移到其它场地。

---

## 0. 问题定义

两次独立 SLAM 扫描同一场馆，得到两份场馆级点云：

- **A（参考扫描）**：ERASOR2 建图结果，已在 SUMA 场馆坐标系，并已有场地级裁剪点云；
- **B（第二拨扫描）**：red1，10.4M 点，自有坐标系、自有尺度；
- **M（官方场地模型）**：RMUC 2026 官方模型（1M 点 PCD），设计尺寸，是"理想资产"。

目标：

```
P_final = shape(M) 在 pose(B ∪ A) 下的采样
```

即：形状/拓扑取官方模型，位姿/尺寸取两次扫描的融合结果，最终表达在场地坐标系
（x∈[0,28] m，y∈[0,16] m，z = 离地高度，地面 z≈0）。

---

## 1. 场馆级粗配准

### 1.1 结构带提取

配准只用场馆的结构部分（看台、环墙、周边建筑），避免地面点和动态物体主导：

```python
band = (z > 2.0) & (z < 12.0)      # 场馆结构带
```

地面点对水平平移几乎没有约束，而动态物体（人、机器人）会造成错误牵引，两者都剔除。

### 1.2 2D 占用 + 全角度旋转搜索

把结构带投影到 XY 平面，0.5 m 栅格，高斯模糊后做旋转-平移搜索：

对每个旋转角 θ ∈ [0, 360)，把源栅格 `B` 绕其质心旋转 θ，用相位相关求最佳平移：

```
corr = IFFT2( FFT2(A) · conj(FFT2(B_θ)) )
score = max(corr) / (‖A‖·‖B_θ‖)
```

得到 `(score, θ, dx, dy)` 候选列表。这一步对整体平移/旋转是穷举的，不会陷局部极小。

### 1.3 多候选 3D ICP

场馆是八角形、存在 45° 旋转对称，单纯 2D 打分可能把对称位置也打高分。
因此取 top-K 候选，分别做 trimmed point-to-point ICP（3D，硬约束尺度 = 1）：

```
each iteration:
  q_i = T · p_i
  d_i = ‖q_i − NN(q_i)‖
  keep = d_i < quantile(d, trim)
  (R, t) = Umeyama({p_i}, {NN(q_i)})   # with_scale=False
  T ← ΔT · T
```

按最终 **chamfer 中位数**选最优候选。脚本会输出全部候选的 score/角度/平移，
便于人工判断是否存在对称歧义。

### 1.4 实测

| 指标 | 值 |
|---|---|
| 初始候选最佳 score | 0.716 |
| 3D ICP 后 chamfer 中位 | 0.137 m（场馆级，含覆盖差异） |
| 2D chamfer 中位（结构带） | 0.064 m |

## 2. 点-面精配准

点-点 ICP 的残差被采样差异限制，且会残留小角度。用 **trimmed point-to-plane**：

目标函数（对左乘扰动 ξ = (v, ω) 线性化）：

```
r_i(ξ) = n_i · (T q_i + v + ω × (T q_i) − y_i)
```

其中 `y_i` 是参考云最近点，`n_i` 是其法向。Jacobian 行（注意顺序）：

```
J_i = [ n_i ,  (T q_i) × n_i ]
```

每轮解 `J ξ = −r`（最小二乘），得到增量 `ΔT = exp(ξ)`，**只有当中位最近邻距离
下降时才接受该步**（线搜索）。法向用 k=16 邻域 PCA 估计。

> 踩坑：早期把 Jacobian 写成 `[p × n, n]`（v/ω 顺序与符号都反了），
> ICP 从 0.25 m 直接发散到 13 m。正确顺序与符号见上式；另外**不要允许尺度自由**，
> 逐轮尺度估计会累积（0.97³⁰ ≈ 0.40，点云被整体缩小）。

## 3. 融合与场地坐标

### 3.1 场馆 → 场地

RMUC 2026 场地在 SUMA 场馆坐标系中的位姿（本项目实测标定）：

```python
R  = rot2d(52.61°)                       # 场地轴相对场馆轴
xy_field = (xy_venue − (8.09, −6.71)) @ R.T + (14.006, 8.265)
h        = z_venue − (a*x_field + b*y_field + c)      # a,b,c = −0.0013, −0.0011, 0.556
h       -= datum                          # 地面直方图峰值归零
```

其它场地只需替换 `rot_deg / center / translate / plane` 四个参数
（见 `configs/example_params.yaml`）。

### 3.2 融合

两云各自转换到场地坐标后按 `[xmin,xmax]×[ymin,ymax]` 裁剪，
参考云直接用（已在地面坐标系），源云做 `datum auto` 对齐，然后拼接。

实测：ERASOR2 场地点 2,459,575 + red1 场地点 8,052,522 → 合并 **4,719,574** 点
（red1 只保留场馆与场地重叠且在地面框内的部分）。

## 4. 去动态 / 去雾 / 地面压平

三连过滤，顺序不能反：

1. **官方模型邻近**：`d(model) < 0.30 m` 才保留。
   人、机器人、杂物不属于场地结构，会被整体剔除；这一步同时把雾的"外围"去掉。
2. **连通块过滤**：0.1 m 体素化，26 连通分量，<100 点的分量删除。
   雾、拖影、人的残影都是小而孤立的块；真实结构是大块连通的。
3. **地面压平**：对 `|z| < 0.35 m` 的点做带剔除的平面最小二乘
   `z = a x + b y + c`，所有点减去该平面。

实测：4,719,574 → 模型邻近后 4,462,737 → 连通过滤后 4,462,347 → 去重后 **1,810,798** 点，
地面 std 约 0.07 m（去重前）/ 0.02~0.05 m（取决于裁剪半径）。

> 注意：模型邻近阈值不要放太松（如 0.25→0.30 看似小改），否则雾会原封不动留下来；
> 早期一次实验 0.25 m 阈值保留了 94% 的点，等于没洗。

## 5. 官方模型形状参照（连续偏移场）

### 5.1 为什么不能整体刚体套模型

官方模型是设计资产，现场装配存在**零件级**安装误差：每块围栏板、每段墙、每个平台
都可能有自己的平移/倾斜。整体刚体配准只能对齐"平均位形"，零件级差异会被抹掉或
造成局部错位。

### 5.2 逐块偏移场

把场地划成 1.5 m × 1.5m 块，对每块：

```
M_block = 模型点
S_block = 扫描中与 M_block 最近邻距离 < 0.35 m 的点
(dx, dy, dz)_block = median(S_block − M_block)      # ≥25 对才有效
```

空块用**距离变换取最近有效块**填充，再 `median_filter(3)` + `uniform_filter(3)` 平滑，
得到连续偏移场 `F(x, y)`。模型点按 `M' = M + F` 移动。

这样：
- 保留了零件级安装差异（中位约 2 mm、P90 5 mm，本场地实装与官方模型高度一致）；
- 因为是连续场，不会像"逐面板独立摆位"那样在接缝处裂开（裂缝率 9.1% → 2.0%）。

### 5.3 证据门控 + 地面压平 + 去重

- 结构点：`dist(M', scan) < 0.35 m` 才保留（避免凭空补出扫描根本没看到的结构）；
- 地面点：模型里 `z ≤ 0.12 m` 的点整体压平到 `z = 0`；
- 2 cm 体素去重，输出 ~759k 点的规整点云。

## 6. 隧道/开口局部修复

官方模型把隧道/通道做成实体（或 5.2 的局部拟合把它闭合），但现场是开口。
做法：人工标注隧道区域（矩形，`configs/tunnel_zones.json`），
**该区域内**删除模型形状点、替换为真实扫描点，区域外保持模型形状。

```json
[
  {"name": "south_tunnel", "x": [11.5, 18.0], "y": [0.5, 3.0]},
  {"name": "north_tunnel", "x": [11.5, 17.0], "y": [13.0, 15.8]}
]
```

实测：南隧道删 25,570 模型点、补 290,143 扫描点；北隧道删 19,893、补 366,560；
修复后 992,979 点，隧道口恢复贯通。

## 9. 踩坑记录（供复现参考）

1. **尺度漂移**：ICP 里放开尺度且每轮重新估计，会出现 `0.97^30 ≈ 0.40` 的收敛，
   点云整体缩小；刚性配准请固定 `scale = 1`。
2. **point-to-plane 雅可比**：v/ω 顺序或符号写错会直接发散；正确形式 `[n, p×n]`。
3. **对称歧义**：八角形场馆 45° 对称、场地 180° 对称，单角度最优不可信，要多候选 + 人工复核。
4. **平面滑移**：单块平面片无法约束面内平移，逐面板位姿不能当安装误差真值。
5. **逐零件硬摆位会裂缝**：每个零件独立 6-DoF 摆位会在接缝处留缝，改用连续偏移场。
6. **清洗阈值**：模型邻近阈值放太松（0.25 m 保留 94%）等于没洗，雾还在。
